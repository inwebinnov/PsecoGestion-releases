# PsecoGestion — téléchargements

Installeurs officiels de **PsecoGestion**, le logiciel de gestion des
psychotropes pour pharmacie, édité par [inwebinnov.com](https://inwebinnov.com).
Ce dépôt ne contient que les fichiers d'installation, publiés dans
[Releases](https://github.com/inwebinnov/PsecoGestion-releases/releases).

## Télécharger la dernière version

- **Ordinateur (Windows)** : ouvrez la
  [dernière version](https://github.com/inwebinnov/PsecoGestion-releases/releases/latest)
  et téléchargez `PsecoGestion-Setup-X.Y.Z.exe`.
- **Téléphone (Android)** : sur la même page, téléchargez `PsecoGestion-vX.Y.Z.apk`.

L'installeur s'installe par-dessus une version existante : les données, la
licence et les mots de passe sont conservés. À partir de la version 1.7.1, le
logiciel se met à jour tout seul.
